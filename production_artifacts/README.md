# production_artifacts

Use this folder for technical outputs created by the agent team.

Examples:

- `Codebase_Analysis.md`
- `Pre_Plan_Recommendations.md`
- `Implementation_Plan.md`
- `QA_Report.md`
- `Runtime_Report.md`
- `Evaluation_and_Recommendations.md`
- screenshots, logs summaries, smoke-test notes, and handoff documents

Do not place application source code here. Source code belongs in `app_build/` unless the user explicitly asks otherwise.
